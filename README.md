# Hi, I'm Emily

I'm a front-end engineer with 15+ years of experience building fast, accessible, and maintainable web applications. I currently lead front-end architecture for HIPAA-regulated clinical software, and delivered work for Netflix, Bloomberg Media, and The Wall Street Journal.

I care about design systems that scale, interfaces that hold up under real load, and code that other engineers can trust. Accessibility and performance are part of the job, not extras.

## What I work on

- **Architecture**: React and Node systems, microfrontends, and enterprise design systems with Storybook and shared component libraries
- **Quality**: TypeScript modernization, WCAG AA, Lighthouse and axe, and release pipelines that stay stable under change
- **Security**: CVE remediation, HIPAA-regulated UI, and standing membership in OWASP
- **Craft**: Clean architecture, thoughtful CSS, and interfaces that feel as good as they look

## Featured projects

- **[Reddit NFL](https://github.com/hmphry/NFL)**: Led the eight-year evolution of the custom front-end theme for [r/nfl](https://www.reddit.com/r/nfl), one of the early major subreddit themes that helped push community-driven design on Reddit.
  > "Sweet Walter Camp, this is amazing! You've made a site the NY Times said has 'the design aesthetic of a ransom note' into something beautiful. Well done mods, well done." (Erik Martin, former General Manager of Reddit)
- **[JS Morse Code](https://github.com/hmphry/js-morse-code)**: A JavaScript Morse code detector that turns touch and mouse tap sequences into events, exploring accessibility and alternative input patterns.
- **[JSMamba](https://github.com/hmphry/JSMamba)**: An open-source, flashcard-inspired quiz platform in TypeScript for active recall and real-time JavaScript practice.
- **[NFC Card](https://github.com/hmphry/NCF-card)**: An end-to-end NFC web app with physical tag integration, dynamic contact profile pages, and downloadable vCards.
